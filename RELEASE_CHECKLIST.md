# Release Checklist

## Before push

1. Open `index.html` and test the planner flow.
2. Toggle `Light / Night` mode and confirm it changes only the UI.
3. Run `Launch-Azerslide.cmd` and create one sample `.pptx`.
4. Confirm button navigation works in the generated PowerPoint.
5. Remove generated sample files that should not be committed.

## Before publishing

1. Review `README.md`.
2. Confirm `.gitignore` covers generated presentation files.
3. Check file names and folder layout are still clean.
4. Make sure the repo root is the folder that actually contains the app files.
